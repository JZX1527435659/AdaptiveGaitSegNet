# Gaitset_ouput: The self-built dataset specially designed for AdaptiveGaitSegNet4PD.

## Usage instructions
The self-built dataset consists of preprocessed images. Please place the folders of this branch under the `gaitset_output` folder of the AdaptiveGaitSegNet4PD model. This dataset can be directly used for training the model without going through the pretreatment.
The structure of AdaptiveGaitSegNet4PD can be found in the `README.md` of the AdaptiveGaitSegNet4PD branch.
